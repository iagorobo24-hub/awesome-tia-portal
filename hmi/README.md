# HMI

Pantallas, plantillas y recursos para paneles **Siemens HMI** (Basic, Comfort, Unified) configurados desde TIA Portal.

Aquí no van proyectos HMI completos — van piezas: una pantalla de alarmas base, una plantilla de navegación, un objeto gráfico para motor...
