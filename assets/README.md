## Capturas reales pendientes

Las capturas de TIA Portal se añadirán cuando exista un proyecto de demostración desechable con versión y objeto identificados. Antes de publicarlas:

1. Comprueba que no muestran datos de cliente, direcciones, nombres de máquina ni rutas personales.
2. Anota versión de TIA, dispositivo, proyecto de demostración, fecha y acción visible.
3. Distingue una captura de editor de una prueba funcional en PLCSIM o Runtime.
4. Incluye texto alternativo y una explicación breve junto a la imagen.

No se sustituirá una captura pendiente por una interfaz generada.
